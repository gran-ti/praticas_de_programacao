# Carrinho de Compras – Projeto Mão na Massa

Projeto da Unidade 4 da disciplina **Desenvolvimento Front-end**: um carrinho de compras feito com HTML, CSS, JavaScript e Bootstrap, a partir de um template pronto.

## Estrutura

```
carrinho-de-compras/
├── index.html          estrutura da página (HTML)
├── carrinho.css        estilos próprios e media queries (CSS)
├── carrinho.js         funcionamento do carrinho (JavaScript)
├── img/                logotipo e imagens dos produtos
└── template-original/  código original do template (HTML e CSS), ponto de partida do projeto
```

Os números de linha citados no material da unidade se referem aos arquivos `index.html`, `carrinho.css` e `carrinho.js` desta pasta.

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta no VS Code e abra o `index.html` com a extensão **Live Server**, ou dê um duplo clique no arquivo para abri-lo no navegador.
3. Use os botões **+** e **–** para alterar a quantidade dos produtos e o botão **×** para retirar um produto do carrinho. O total de cada produto, o subtotal e a quantidade de itens são calculados automaticamente.

É preciso estar conectado à internet, porque o Bootstrap e os ícones (Font Awesome) são carregados por CDN.

## Créditos

Layout baseado no template *Bootstrap ecommerce cart page template*, do BBBootstrap (a página original não está mais disponível; o código está na pasta `template-original`). Produtos e logotipo: Loja Gran.
